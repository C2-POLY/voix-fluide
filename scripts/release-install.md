Voix Fluide : dictée vocale pour macOS, entièrement sur le Mac. Voice dictation for macOS, entirely on the Mac.

## Installer

1. Téléchargez `Voix-Fluide.dmg` et ouvrez-le.
2. Glissez Voix Fluide dans Applications, puis ouvrez-la depuis Applications.
3. L'app n'est pas notarisée : au premier lancement, macOS la bloque. Allez dans Réglages Système › Confidentialité et sécurité et cliquez « Ouvrir quand même ».
4. Autorisez le micro, puis l'accessibilité (pour coller le texte).

Mac Apple Silicon uniquement. Les mises à jour s'installent depuis la page Mises à jour de l'app.

Sans certificat Apple (Apple Development ou Developer ID) dans le trousseau, Voix Fluide ne peut pas se signer elle-même : macOS redemande alors le micro et l'accessibilité après chaque mise à jour.

## Install

1. Download `Voix-Fluide.dmg` and open it.
2. Drag Voix Fluide to Applications, then open it from Applications.
3. The app is not notarized, so macOS blocks it on first launch. Go to System Settings › Privacy & Security and click "Open Anyway".
4. Allow the microphone, then Accessibility (to paste the text).

Apple Silicon Macs only. Updates install from the app's Updates page.

Without an Apple certificate (Apple Development or Developer ID) in the keychain, Voix Fluide cannot sign itself: macOS then asks again for the microphone and Accessibility after each update.
